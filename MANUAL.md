# MANUAL DO USUÁRIO - CHECKPRO (CHECKLIST INDUSTRIAL)

## 1. TELA DE CARREGAMENTO (SPLASH)
Ao abrir o aplicativo, uma tela de carregamento é apresentada enquanto o banco de dados local e os usuários são inicializados de forma automatizada.

## 2. AUTENTICAÇÃO OBRIGATÓRIA
* O aplicativo só libera as telas de checklist e histórico **após o login em uma conta válida**.
* **Conta Administradora Padrão**:
  * **Usuário:** `master`
  * **Senha:** `master`

## 3. ÍCONES ILUSTRATIVOS E NAVEGAÇÃO
* Todos os itens de checklist possuem ícones representativos para facilitar a identificação visual rápida por parte dos operadores em campo.
* Ao clicar no botão **CHECKPRO** no topo da tela, você é redirecionado instantaneamente para o painel principal.

## 4. OPÇÕES DE NÃO CONFORMIDADE (NC)
* Ao selecionar a opção **Não Conforme (NC)** em qualquer item, o sistema exibe um menu suspenso com opções predefinidas (ex: *Vazamento detectado*, *Danificado ou quebrado*, *Componente solto*, *EPI ausente*).
* Caso o problema não esteja na lista, o operador pode escolher a opção **Outro** para abrir um campo de texto livre e descrever detalhadamente o defeito.

## 5. PAINEL DE GESTÃO DO ADMINISTRADOR
* **Alteração de Senhas**: O administrador pode alterar a senha de qualquer operador registrado no sistema.
* **Exclusão de Registros**: Apenas administradores possuem o botão para deletar checklists do histórico.
